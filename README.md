# Дашборд: планирование перевозок по Яне (кейс А3)

React + Vite, работает локально. Показывает готовые расчёты оптимизатора 2.1.0 (FCFS против OPTIMIZED)
и ничего не пересчитывает сам.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install      # один раз
npm run dev      # откроет http://localhost:5173
```

Данные уже лежат в `public/data`, Python для просмотра не нужен.

## Экраны

1. **Сравнение стратегий** (открывается первым): доставка в срок, всего, недоставленное, рейсы, разница в тоннах
   и процентах, разбивка по грузам, прирост по всем 114 сценариям.
2. **Расписание**: диаграмма Ганта по составам, допустимая осадка сценария, накопленная доставка, список рейсов.
3. **Сценарии**: как флот, спрос, окно навигации, глубины и сроки готовности меняют доставку в срок; таблица всех сценариев.
4. **Обзор и ограничения**: северный завоз, опубликованная статистика, ограничения модели, реальные и синтетические
   параметры, источники.

Сценарий выбирается сверху на экранах 1 и 2; адрес страницы хранит экран и сценарий (`#/compare/r1_baseline`).

## Обновление данных после нового расчёта

```bash
python tools/export_data.py <папка Case_a3>
```

Скрипт (только стандартная библиотека) читает `comparison_final.csv`, `ml_scenario_results.csv`,
`final_results/*/{fcfs,optimized}.json` и `data/scenarios/*` и пишет `public/data/model/index.json`
и по одному файлу на сценарий. Метрики берутся из файлов оптимизатора как есть. Производных две:

- срок партии присоединяется к рейсу по `cargo_id` из `cargo.csv`, признак «в срок» = разгрузка не позже срока
  (определение из `RESULT_CONTRACT.md`); сумма сверяется с `delivered_on_time_t`, при расхождении признак не показывается;
- накопленная доставка — сумма тоннажа рейсов по моментам окончания разгрузки.

Для 12 результатов со старыми именами (`baseline`, `shallow`, `high_demand`, `short_navigation`) входные данные
сопоставлены с каталогами `*_central_central` по составу грузов. Для `scarce_fleet` и `excess_fleet` входных
каталогов в архиве нет: допустимые осадки и загрузка рейсов для них не показываются.

## Структура

```
public/data/model/        результаты оптимизатора (index.json + scenarios/*.json)
public/data/*.csv         официальная статистика, параметры, источники, позднее сообщение ЯСИА
tools/export_data.py      подготовка данных из папки Case_a3
src/App.jsx               навигация и выбор сценария
src/model.js              загрузка результатов, подписи, форматирование
src/screens/              Compare, Schedule, Scenarios, Overview
src/components/           выбор сценария, разрез бара, этапы завоза, таблицы
```

## Чего нет намеренно

Очереди у бара, стоимости, зимника, вероятностей и доверительных интервалов модель не считает, поэтому на дашборде
их нет. ML-прогноз и интерактивный пересчёт параметров не подключены.
